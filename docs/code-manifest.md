# Code manifest

What every code file does, in the order a request flows through it. When you add, remove, or rename a code file, update this list; a test fails if a file is missing here. The bigger picture is in [ARCHITECTURE.md](ARCHITECTURE.md).

## Student app: what runs on the home server

**Starting the server**

| File | What it does |
|---|---|
| `src/lerni/commands/serve.py` | The `lerni serve` command: starts the student app, with a friendly message if Gradio isn't installed; `--cert` and `--key` serve HTTPS; `--label Development` marks a development server. |
| `src/lerni/commands/service.py` | The `lerni service` commands: install, restart, stop, uninstall, and check the student app's LaunchAgents (prod and dev); install shows setup warnings, and install and restart wait for the server to answer. |
| `src/lerni/student/service.py` | Runs the student app as a macOS LaunchAgent: writes the agent from the server's settings and the shell's `LERNI_*` settings (paths found at install time), refuses either server on the other's data or port, warns about missing tools or production off `main`, loads, restarts (rotating a big log; starting a stopped one), and stops it with `launchctl`, says whether it's answering, and waits for it to. |
| `src/lerni/student/web/serve.py` | Says which code is running (branch, commit, date), picks the Claude chat, tagger, uploader, and race-question writer if the `claude` CLI is installed, builds the app, says how to add the first educator if there's none and where the logs are, says whether voice is on (the speech tools are installed), and runs the web server (HTTPS with `--cert` and `--key`) (Ctrl-C stops it within 3 seconds). |
| `src/lerni/student/web/app.py` | Builds the server: the sign-in page, and one Gradio app at `/app/` that Gradio's `auth_dependency` re-checks on every request; wires the conversation to the map keeper (maps, tagger, logs), Upload to the uploader, Games to the points store and the race desk (each supervised student's next race written at startup), and Feedback to `feedback.jsonl` and purges old logs at startup. Turns off Gradio's analytics, run history, API pages, and other extras, and sets the look (system fonts, 16px fields). Inlines `nav.js` and `mapview.js`; with speech on, also `talk.js`, and gives the held talk button its look. |
| `src/lerni/student/web/signin_page.py` | The sign-in page: a plain HTML form Safari can save, the signed cookie (`Secure` over HTTPS; a labeled development server uses its own, so signing in there doesn't sign a phone out of production), Sign out (this device only), and sending signed-out visits to it; shows the running version small at the bottom. |
| `src/lerni/student/web/main.py` | The one app's page: a ☰ menu (who's signed in, their sections, Sign out) and the open section's name, then tabs by role on load (the tab bar itself hidden): a supervised student's conversation, full screen, and Games; Chat, My MentalMap, and Settings; MentalMaps and Games for educators, who open on it and see it by their student's name when they have one (`menu_label`, `opening_tab`, `picker`). A player's ⭐ shows in the header, and their next race's questions start writing at sign-in. Educators see a Claude usage warning near a limit. Nothing per-user or from the data is built into the layout. |

| File | What it does |

| `src/lerni/student/web/ask.py` | The conversation: an independent student's Chat tab (chat, one-line question box, Send that becomes Stop, New conversation; educators can try the supervised-student voice) and a supervised student's whole screen (chat, box, Send/Stop). One ongoing conversation per student; phone first. A supervised student always gets the supervised voice; the role is checked on the server. With speech on, a dock under the chat holds a big round Hold to talk button or, after Type, the question box: a live preview while it's held, what was heard becomes the student's message, every answer (typed too) is spoken a sentence at a time, and pressing the button stops any answer. |

| `src/lerni/student/web/games.py` | Games for supervised students and educators: race two rival cars (the next Showroom car and an owned slower one, or the bots) by tapping one of three answers (the page sends the race id, question number, and button, never seeing the answer), then the garage (buy with points, drive what you own). After a wrong answer the card keeps that question with its right answer and why until **Next** (`question_card`). Race! shows a waiting note, with no loading overlay on the garage. Plain handlers over the server-resolved viewer; the educator's read of a student's points goes through `map_owner`. The bonus card: typed or Hold to talk (the `bonus` dock), Send or Skip, then its grade until Next. `student_progress`: a student's goal progress this week grouped by area (a bar per goal), ⭐, and car, for their educator. |
| `src/lerni/student/web/race.js` | The race in the browser: each car glides from its last place to its new one when the track is redrawn (it jumps with reduced motion); the Race! tap unlocks sound, each answer plays the roar or the sputter and the last the finish, cut short with a fade, and one Sound switch is remembered on the device; with sound on, a tap on the card reads it, a wrong answer's right answer is said by itself while Next waits (20 seconds at most), and a tap that moves on stops a reading. |

| `src/lerni/student/web/mentallist.py` | A MentalMap as a list, on My MentalMap and MentalMaps: add a goal or an interest; tap an item for its strength, facts (a goal's Practice line from the race results), notes, Rename, its group (Kind of, Not under X), and its kinds, bridges, and related items (bridges and related items with their link's strength); 🗑 removes it to Removed, where Put back restores it and Delete for good erases its history; Older interests lists what a full map rested, read only; an open item's Also called lists its other names, each with Not the same. | `src/lerni/student/web/mapdraw.py` | Draws a map as inline SVG: every entry, linked ones clustered and goals in the middle, from a seeded layout so a redraw never moves anything; sized by the list's strength, color-blind-safe green and coral, dashed bridges, every name escaped. |
| `src/lerni/student/web/mapview.js` | The picture in the browser: tap an item to light up its links and open it in the list, scrolled into view; pinch (or Ctrl and scroll) to zoom, drag once zoomed, Reset view; keeps zoom and the tapped item across redraws. |

| `src/lerni/student/web/__init__.py` | Marks the screens package; says it's the only place Gradio is imported. |

**The core** (standard library only; no Gradio, no provider SDKs)

| File | What it does |
|---|---|
| `src/lerni/student/interests.py` | Interest maps (every change journaled, under a lock shared with `lerni map`): entries (interests and goals), links (with the days they came up: a strength, and a bridge's held days and bounces), the rules for people's edits (add a goal or an interest, names, the 60-entry cap, remove, Put back with its history, and Delete for good) and for the tagger's observations, "kind of" groups (at most 2 per item, no loops, 3 levels; a group counts each day any kind came up) and "car" finding "cars" (real plurals only: never plan and planes; "race cars" finding "racecars"), items with other names joined by the tagger's same-as or split by a person, a full map resting its least-seen interest until it comes back, each item's strength and details, the map block for the prompt (goals tied on coverage take turns by day; removed interests listed as set aside; groups with their recent kinds; whole lines only), and `MapStore` (one JSON file per student, one change at a time).; each goal's subject area (`set_area`, `by_area`, generic `STARTER_AREAS`) |
| `src/lerni/student/points.py` | Points: one JSON file per person (ids and numbers only); each award or purchase applies once by its id, Chat stops at 30 a day, buying a car never goes below zero, and 10 races a day. |
| `src/lerni/student/garage.py` | The garage: cartoon cars drawn as SVG in code, and real cars read once from the private `garage.json` (a bad entry or file is skipped); prices at $2,500 a ⭐, the gas boost from 0–60 (×1.0 to ×1.4), what each player's garage lists, the cars in reach whose facts race questions use, each player's two rivals, and each car on the track. |
| `src/lerni/student/concepts.py` | Race concepts: one JSON file per player, a ledger kept for good of every idea race questions tested (labels, goals, first and last dates, times asked and right; never question text); "asked lately" is the last 40 within 14 days; each goal's level (1 to 5, from 3), moved by every 5 answers on it; missed ideas due again after 1, 3, then 7 days, retired after three right; each goal's box (1, 3, 7, or 14 days) moved by every finished race (`raced`, `schedule`); v3.9 and v3.10 files load. |
| `src/lerni/student/results.py` | Race results, kept for good: one JSON line per answer (day, race, goal, concept, a question hash, right or wrong, seconds) and per finish (place, points, version), never question text; this week per goal (by id) for the educator, questions per goal for picking, and a goal's Practice line (last raced, this week, ideas missed lately). |
| `src/lerni/student/race.py` | The race: Haiku's question instructions and schema, the input from a student's map (goals at their levels, the cars in reach with their facts, and missed ideas due for review), checks that drop bad, off-map, or repeated questions (by concept, or nearly the same words) and shuffle choices, the server's own sums (mixed numbers like "3 and a half" read right) and a blind second check so a wrong key never races, fixed race rules (the finish depends only on how many were right), and `pick_goals` (each set's 5 goals: due first, mixed by area), `spoken_question` and `RaceDesk` (questions written ahead and kept past midnight, the question on screen, or a wrong answer's right answer and why, read aloud once and kept in memory (`read_aloud`, `read_why`), one race per person, points at the finish, each answer logged); the bonus round (an explain-it question as question 4 by a 1-in-4 draw, graded by the small model against its key ideas, fenced off as information: nailed, partly, tried, or none; a worrying answer gets Chat's caring words and no points and goes to the conversation log; any other answer is kept in memory only) |
| `src/lerni/student/tagging.py` | The tagger's instructions and schema (with `same_as` for the very same thing), its input (each item's other names), and `MapKeeper`: tags each exchange in the background, applies it under the map's lock unless a person changed the map or the conversation was cleared, and logs it. |
| `src/lerni/student/journal.py` | The map journal: each map change (who made it, and the items before and after) appended to `maps/<user>.events.jsonl` after a baseline; `diff`, `replay` (a map from its journal), `undo` (one change reversed, keeping what only grew since; refused when a later change did more to the same items), and a names-only summary. |
| `src/lerni/student/backup.py` | Nightly backups: copy the data folder to `~/.lerni/backups/<its name>/nightly-<date>/`, keep the newest 30 (never other folders there), and the LaunchAgent that runs it at 03:00. |
| `src/lerni/student/logs.py` | Conversation logs: each exchange and what the tagger did, one file per student per day, deleted after a year; the only place message text is saved. |
| `src/lerni/student/usage.py` | Claude usage: the latest share used of each limit and when it resets; a warning line for educators at 75% of the week or 80% of the 5-hour window, and a pause at 95% or on any paid extra usage. |
| `src/lerni/student/voice.py` | Voice: checks a spoken clip (a WAV of at most 30 seconds) and gets what was said; cuts Lerni's answer into clean sentences to speak (no markdown, emoji, or web addresses); a failed voice leaves the text, a silent sentence is skipped, and a transcript of only unreadable letters counts as heard nothing. Keeps no audio. |
| `src/lerni/student/upload.py` | Upload: reads pasted notes and .txt/.md/.docx/.pdf files, the instructions and schema for Claude's proposals, and checks and adds the ticked interests and goals. |
| `src/lerni/student/educator_agent.py` | The educator agent: its persona and rules, a reply whose fenced `proposals` block is hidden as it streams, checking proposals (goal with its area, interest, reword, remove, group, feedback, area) against the map, applying only ticked ones, and each educator's chat about each student in memory (plus the log). |
| `src/lerni/student/feedback.py` | Educator feedback: saved one line per entry in `feedback.jsonl`, summarized by Claude with instructions never to carry it out, listed and closed only by `lerni feedback`. |
| `src/lerni/student/fence.py` | One fence for student text sent to Claude (the bonus grader, the tagger, Upload): every mark of its tag inside is removed until none is left (v3.31). |
| `src/lerni/student/students.py` | Student accounts: usernames, kinds, scrypt password hashes, the data folder (`default_data_dir`), and `StudentStore` (one JSON file per student; archived in place, never reused). |
| `src/lerni/student/signin.py` | Signing in: checks passwords (with growing waits after wrong ones), issues a signed cookie, and re-reads the account on every request, so archive and reset sign out every device. |
| `src/lerni/student/jsonfiles.py` | Writes a JSON file atomically; shared by the plan and student stores. |
| `src/lerni/student/conversation.py` | Chat with Lerni: each student's conversation in memory (last 20 turns, one reply at a time), and Claude's instructions: the starting persona for that kind of student, their map as information, then fixed safety rules (including steering away from what a person set aside); reports each finished or stopped exchange so the map can grow, never who is asking. |
| `src/lerni/student/__init__.py` | Marks the student package; states the standard-library-only rule. |

**Outside services** (the only code that imports provider SDKs)

| File | What it does |
|---|---|
| `src/lerni/student/adapters/claude_code.py` | Claude through the Claude Code CLI and the logged-in account (prototype; no API key): streams Chat with Lerni's answers, tags each exchange for the map (a small model, JSON only), proposes map entries from uploaded notes, and writes race questions (the small model, JSON only). | `src/lerni/student/adapters/__init__.py` | Marks the adapters package. |
