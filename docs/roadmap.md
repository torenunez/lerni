## Versions

- **One number per PR:** `<major>.<minor>`. The major is a row in the table above; each merged PR, docs-only too, is the next minor (`2.7`, `2.8`, …).
- **The PR carries it:** its title starts `v2.8:`, it sets `version` in `pyproject.toml`, and `main` is tagged `v2.8` when it merges.
- **What's running:** each server's sign-in page shows its version, e.g. `v2.8 · main @ 1a2b3c4`; development shows the number its branch will ship as.
- **Planned ahead:** the next numbers are listed in [upcoming versions](todo.md#upcoming-versions); plans are named `plans/v<major>.<minor>-<name>.md` ([starting points](../plans/README.md)). The admin tool has no versions of its own; its upkeep is in the [to-do list](todo.md#admin-tool-maintenance).
