# Roadmap

The plan: the student app's releases in order, what each needs first, what completes it, and where each stands. Mark a release done only with evidence in [progress](progress.md). Tasks: [to-do list](todo.md). Requirements: the [student](prd/student.md) and [educator](prd/educator.md) PRDs.

| Release | Needs first | Done when | Plan | Status |
|---|---|---|---|---|
| [1 — MVP](prd/student.md#release-1-answer-questions-about-something-you-love) | Building needs nothing; the educator's planning in the app runs in parallel. Before a supervised student tries it: one approved activity | It runs on the home server with sign-in; the admin, as an independent student, has done their own activity end to end; a supervised student uses it on the iPad while the educator controls it from their own device; the educator has rehearsed and authorized it; the student has tried it; and the signals in the educator's [in-app guide](../src/lerni/student/web/guide.md#watching-the-student-try-it) are recorded privately ([progress](progress.md) notes only the date) | [release-1-mvp.md](../plans/release-1-mvp.md), [student accounts design](../plans/specs/03-student-accounts.md) | In progress: steps 1–4 merged (skeleton, listing, planning, Claude import); steps 5–8 next. The educator hasn't planned in the app yet; no activity approved |
| [2 — Remembering](prd/student.md#release-2-the-app-remembers-me) | Release 1 | Each activity is mapped to the concepts it teaches; the app remembers progress and builds on it; an idea is reused across two interests; later recall is checked | Not written | Not started |
| [3 — Voice](prd/student.md#release-3-talk-with-the-app) | Release 2; the voice decisions; a plan for the conversation agent (with tools) and its evals | It runs on the iPad over HTTPS on the home server; the educator has agreed to the speech services | Not written | Not started |
| [4 — New ideas](prd/student.md#release-4-new-ideas-grow-from-old-ones) | Release 3 | The app proposes and drafts connected activities; the educator approves each | Not written | Not started |
| [5 — Free conversation](prd/student.md#release-5-explore-freely) | Release 4 reliable, and a safety review of the checks, since this release replaces the present educator with prototype guardrails | The student converses without an educator involved; the educator monitors the concept map and answers rare consent requests | Not written | Not started |

Plans are named `plans/release-<n>-<name>.md` with the short names above (`mvp`, `remembering`, `voice`, `new-ideas`, `free-conversation`), and each is written when its release starts; [starting points](../plans/README.md). The admin tool has no releases; its upkeep is in the [to-do list](todo.md#admin-tool-maintenance).
