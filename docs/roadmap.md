# Roadmap

The plan: the student app's releases in order, what each needs first, what completes it, and where each stands. Mark a release done only with evidence in [progress](progress.md). Tasks: [to-do list](todo.md). Requirements: the [student](prd/student.md) and [educator](prd/educator.md) PRDs. Design: [interest map spec](../plans/specs/04-interest-map.md).

| Release | Needs first | Done when | Plan | Status |
|---|---|---|---|---|
| [1 — MVP](prd/student.md#release-1-talk-about-what-you-love) | Building needs nothing. Before a supervised student tries it: a few goals, and the educator has rehearsed it | It runs on the home server with sign-in; the admin and educator talk with Lerni and see their maps grow, with at least one bridge to a goal; the educator sets goals on a supervised student's map, sits beside them for a short conversation, and sees the map grow; feedback reaches the admin; and the educator's [watch-for signals](prd/educator.md#what-to-watch-for-in-the-first-sessions) are recorded privately ([progress](progress.md) notes only the date) | [release-1-mvp.md](../plans/release-1-mvp.md), [interest map spec](../plans/specs/04-interest-map.md) | In progress: steps 1–10 built; the first supervised sessions next |
| [2 — Voice](prd/student.md#release-2-talk-with-the-app) | Release 1; HTTPS on the home server | Hold-to-talk on top of the conversation: what Lerni heard shows in the chat and is sent at once, and Lerni answers aloud, a sentence at a time; speech-to-text and text-to-speech run on the home server, so no audio leaves the house; it works on the iPad | Not written | Not started |
| [3 — Remembering](prd/student.md#release-3-a-companion-that-remembers-me) | Release 2 | The companion remembers what each student likes and asks a recall question about an earlier idea after a gap | Not written | Not started |
| [4 — Suggested goals](prd/student.md#release-4-new-goals-from-the-map) | Release 3 | The agent suggests goals from the map; the educator accepts each | Not written | Not started |
| [5 — Without an educator present](prd/student.md#release-5-conversation-without-an-educator-present) | Release 4 reliable, and a safety review, since this replaces the present educator with prototype guardrails | A supervised student talks with Lerni without an educator beside them; the educator glances at the map and answers rare consent requests | Not written | Not started |

Plans are named `plans/release-<n>-<name>.md` with the short names above (`mvp`, `voice`, `remembering`, `suggested-goals`, `without-educator`), and each is written when its release starts; [starting points](../plans/README.md). The admin tool has no releases; its upkeep is in the [to-do list](todo.md#admin-tool-maintenance).
