# v3.12 One item with many names: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop splitting hairs over names. "Volcano", "volcanoes", "race cars" and "racecars", or "T-Rex" and "Tyrannosaurus", become **one map item that keeps every name the student used**. Its history (days, mentions, links) stays together. A person can split a name back out.

**Architecture (`interests.py`, `tagging.py`, `web/mentallist.py`):**
- **Data:**
  - `Entry.aliases: list[str]`: other names for the item, as the student said them.
  - `InterestMap.not_same: list[list[str]]`: casefolded name pairs a person split. Neither tidying nor the tagger joins them again.
  - Old maps load with both fields empty.
- **Tidying (no model):** `same_name` also matches names that differ only in spaces, hyphens, apostrophes or punctuation ("race cars", "racecars", "race-cars"), on top of plurals.
  - `InterestMap.find` matches an item's name or any of its aliases, unless the pair was split.
  - When the tagger names an item by a different spelling, that spelling is added to the item's aliases. The item's name never changes.
- **The tagger's "same as":** a new field, `same_as`: up to 2 pairs [the name the student used, a name on the map], for the *very same* thing.
  - "Same as" covers T-Rex and Tyrannosaurus, but never a kind of it (Mount Etna → volcanoes) or something related (lava → volcano).
  - **The server applies it only when:**
    - the student said the first name;
    - neither name is set aside;
    - the pair wasn't split.
  - **If the first name isn't on the map,** it becomes an alias of the second, and today counts there.
  - **If both are on the map,** they merge into one item:
    - days are joined, mentions added, and goals' explained and bounce dates joined;
    - links move to the kept item, and links to itself are dropped;
    - the other item's name and aliases become aliases.
  - **Which item is kept:** a goal over an interest. Two goals are never merged. A goal's name and notes never change.
- **Set-asides cover aliases:**
  - Removing an item saves its aliases in Removed, and `is_removed` and `mentions_set_aside` check them too. So setting aside "volcano" also blocks "volcanic eruption" in Chat's prompt, the tagger, and races.
  - Put back restores the aliases.
- **Resting items keep their aliases** (`_wake` matches them).
- **Screen:** an item's details on both MentalMap lists show **Also called** with each alias and a **Not the same** button.
  - Splitting removes the alias and remembers the pair. The history stays with the item; the next time the name comes up, it starts its own item.
- **The tagger's input** lists each item's aliases ("volcano (interest; also: volcanoes)") so it answers with the item's name.
- **Also:** the startup line says "Chat", not "Ask Lerni". The admin reference no longer says Time Machine backs Lerni up; backups become a to-do for later.

**Tech Stack:** Python 3.11+ standard library, Gradio 6.30 (`gr.render`, existing), pytest; `scripts/eval_tagger.py` (real Claude calls, by hand).

**Spec:**
- [spec 04](specs/04-interest-map.md): the map;
- [spec 08](specs/08-kind-of.md): groups. Its "no aliases" exclusion is lifted for this, as decided by the admin on 2026-10-20.
- The decisions: merges happen on their own and are reversible with **Not the same**; spec 10's embedder later only shortlists candidates for "same as".

## Global Constraints

- **Rule 5:** only people set goals. "Same as" never creates a goal, renames one, or changes its notes. An interest merged into a goal brings only its history.
- **Set-asides win:** nothing set aside is joined, woken, or re-added through an alias.
- **Rule 6:** aliases are short names from the student's own words, like map names today.
- **Tests:** one new test for the merge rules (a safety guarantee: set-asides and goals), one for split and set-aside through aliases. Two eval cases.
- **Phone-size check** of the details panel as an educator with both lists, right after a restart (CLAUDE.md rule 9).

## Review Focus

1. **Linked items merge:** a link between the two items disappears rather than pointing at itself, and a group can't become its own kind.
2. **Merging a group with a kind of itself,** for example when the tagger says "sharks" is the same as "great white".
3. **The map cap:** a merge frees a slot and never archives anything.
4. **Renaming an item to one of its aliases:** that alias is dropped from the list.
5. **Old maps and old Removed entries without aliases** still load and Put back.
