# v3.6 Production keeps running on its own: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Production and development run as macOS LaunchAgents, so that:
- they start when the admin logs in;
- they restart by themselves after a crash;
- they keep running whatever happens to the Claude app or a Terminal window.

On 2026-10-18 production went down with a Claude app restart, because it ran in the app's Terminal panel.

**Architecture:**
- **`src/lerni/student/service.py`** is a small module with no screens. It turns a server's settings into a launchd property list, and runs `launchctl` through an injectable runner, so the tests never touch launchd.
- **`lerni service`**, a new command group, does the work:
  - `install prod|dev` writes `~/Library/LaunchAgents/com.lerni.<name>.plist` and loads it;
  - `restart`, `stop`, `status` and `uninstall` do what they say.
- **The agent runs** the installing checkout's own `.venv/bin/lerni serve …`, in the user's desktop (Aqua) session, so `say`, `whisper-cli`, the `claude` CLI and its keychain sign-in work as they do in a Terminal window.

**Tech Stack:** Python 3.11+ (`plistlib`, `subprocess`), typer, macOS `launchctl` (`bootstrap`, `bootout`, `kickstart`, `print`), pytest.

**Spec:** the to-do's v3.6 row and the [admin reference: Updating the home server](../docs/reference/admin.md#updating-the-home-server). There's no spec file, because this is operations work.

## Global Constraints

- **Nothing personal in the repo** (rule 8): no home paths, hostnames, or usernames in code, tests, or docs. Paths are worked out at install time from `Path.home()`, the checkout, and the options. Labels are generic: `com.lerni.prod`, `com.lerni.dev`.
- **Same command line as today:**
  - production: `lerni serve --cert … --key …`, port 7860;
  - development: `--port 7861 --label Development`, plus `LERNI_STUDENT_DATA=<dev data>`.
- **The agent's environment** gets the installing shell's `PATH`, so `claude` and `whisper-cli` in `/opt/homebrew/bin` are found. Nothing else is copied: no keys, no tokens.
- **Logs** go to `~/Library/Logs/lerni/<name>.log`. The server already prints no message text (rule 6; `access_log=False`). Install starts the log fresh.
- **Restart after a crash:**
  - `KeepAlive` true, `ThrottleInterval` 10, `RunAtLoad` true;
  - `LimitLoadToSessionType` Aqua (the desktop session; `say` made empty audio over SSH and tmux).
- **Rule 10:** the family keeps using production while this is built. Development is switched over first. Production switches only after the PR merges and the admin stops the Terminal.app copy.
- **Tests (rule 4):** one happy-path test for the module (the plist, and the `launchctl` calls in order). No test calls `launchctl`.

## Review Focus

- **The Terminal.app copy still holds port 7860** when the agent loads. The agent would retry every 10 s and log "address already in use". `status` must show that it isn't answering, and the docs must say to stop the old copy first. Task 3's hand check covers it.
- **Installing twice** (to change a flag) must replace the agent, not fail with "already loaded". Install runs `bootout` first and ignores "not loaded". Task 2's test covers it.
- **After a reboot** the agents start only once the admin logs in, which is how LaunchAgents work. The docs must say so plainly.
- **Restarting development on another branch:** `lerni service restart dev` picks up the new code, because the agent runs whatever the checkout holds. Task 3's hand check covers it.
- **The `claude` CLI under launchd** must still be signed in. If it isn't, startup prints that Claude is off, and the log shows it. Task 3's hand check covers it.

```python
"""Run the student app as a macOS LaunchAgent: starts at login, restarts after a crash.

Paths come from the machine at install time; nothing personal is kept in the code.
"""

from __future__ import annotations

import os
import plistlib
import subprocess
import sys
from collections.abc import Callable
from dataclasses import dataclass
from pathlib import Path
from typing import Any

PREFIX = "com.lerni."  # com.lerni.prod, com.lerni.dev


@dataclass(frozen=True)
class Server:
    """One server's settings, as `lerni serve` takes them."""

    name: str  # "prod" or "dev"
    port: int
    label: str  # shown on every page; "" for production
    data: Path | None  # LERNI_STUDENT_DATA, or None for the default
    cert: Path
    key: Path


def agent_label(name: str) -> str:
    return PREFIX + name


def log_path(home: Path, name: str) -> Path:
    return home / "Library" / "Logs" / "lerni" / f"{name}.log"


def plist(server: Server, lerni: Path, checkout: Path, path_env: str, home: Path) -> bytes:
    """The LaunchAgent for this server, as a property list."""
    args = [str(lerni), "serve", "--port", str(server.port)]
    args += ["--label", server.label] if server.label else []
    args += ["--cert", str(server.cert), "--key", str(server.key)]
    env = {"PATH": path_env}  # so claude and whisper-cli are found
    if server.data is not None:
        env["LERNI_STUDENT_DATA"] = str(server.data)
    log = str(log_path(home, server.name))
    return plistlib.dumps({
        "Label": agent_label(server.name),
        "ProgramArguments": args,
        "EnvironmentVariables": env,
        "WorkingDirectory": str(checkout),
        "RunAtLoad": True,
        "KeepAlive": True,  # restart after a crash
        "ThrottleInterval": 10,  # at most one restart every 10 seconds
        "LimitLoadToSessionType": "Aqua",  # the desktop session: say needs it
        "StandardOutPath": log,
        "StandardErrorPath": log,
    })


Runner = Callable[..., Any]


def install(server: Server, run: Runner = subprocess.run, home: Path | None = None,
            lerni: Path | None = None, checkout: Path | None = None,
            path_env: str | None = None, uid: int | None = None) -> Path:
    """Write the agent and load it, replacing one already loaded.

    Returns:
        The property list's path.
    """
    home = home or Path.home()
    lerni = lerni or Path(sys.executable).parent / "lerni"  # this checkout's own venv
    checkout = checkout or Path(__file__).resolve().parents[3]  # src/lerni/student/ -> root
    uid = os.getuid() if uid is None else uid
    path = home / "Library" / "LaunchAgents" / f"{agent_label(server.name)}.plist"
    path.parent.mkdir(parents=True, exist_ok=True)
    log = log_path(home, server.name)
    log.parent.mkdir(parents=True, exist_ok=True)
    log.write_text("")  # a fresh log
    path.write_bytes(plist(server, lerni, checkout, path_env or os.environ.get("PATH", ""), home))
    run(["launchctl", "bootout", f"gui/{uid}/{agent_label(server.name)}"],
        capture_output=True)  # an older one, if loaded; "not loaded" is fine
    run(["launchctl", "bootstrap", f"gui/{uid}", str(path)], check=True)
    return path
```

Then `restart` (`launchctl kickstart -k gui/<uid>/<label>`), `stop` (`bootout`), `uninstall` (`bootout`, then delete the plist), and `status`. Each takes `name, run=subprocess.run, uid=None`, plus `home` for uninstall and status. `status` returns one line:
- "running (pid N), answering on :PORT";
- "loaded, not answering: see <log>";
- "not installed".

It reads the pid from `launchctl print` (find `pid = N`) and tries `https://localhost:PORT/signin` with `urllib` and an unverified SSL context, timeout 3 s. The port comes from the plist.
