# v3.35: the new order (docs)

**Goal:** The roadmap, PRDs, to-do list, and rules follow the admin's new order: probes, embeddings, an educator's Chat that takes goals and right answers and labels Claude's questions, suggested goals, then recall from what the educator checked.

**Why (the admin, 2026-10-30):** probes, embeddings, remembering, and suggested goals matter most. Probes start the data that suggestions need, and nothing else blocks them. The fact-card library felt like the wrong tool: the educator would rather mark Claude's examples right or wrong, like a labeler, or give goals and right answers through Chat.

**The admin's decisions (2026-10-30):**
- **Order:** v3.36 probes; v3.37 spec 10 (local embeddings); v3.38 embeddings built; then Versions 4–7 below.
- **Numbers follow shipping order,** so Versions 4–6 are renumbered, and tags always read in order.
- **The fact-card library is dropped.** A **checked bank** replaces it: questions and right answers, per goal, that an educator marked ✓ or uploaded.
- **Rule 6 gains one exception:** the checked bank's questions and answers are saved as text. Only what an educator approved or uploaded; never anything a student wrote. Unchecked race questions stay unsaved, as today.
- **One Chat (the old v3.35) is split:**
  - Chat proposing goals goes to Version 4 (the educator's) and Version 5 (suggested goals);
  - an educator's notes about any student go to Version 4;
  - feedback about the app through Chat, and the independent student's own goal proposals in Chat, go to Later.
