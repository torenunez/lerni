# v3.40: local embeddings built

**Goal:** Race questions that reword a recent idea, or that touch a set-aside topic in other words, are dropped before the student sees them. An interest set aside to stop chatting about it no longer blocks the goals it shares a subject with. It runs per [spec 10](specs/10-local-embeddings.md).

**Why:** the admin's two chosen uses (2026-11-09), and "goals win".

## What changes

- **The adapter (`src/lerni/student/adapters/llama_embed.py`, new):**
  - `LlamaEmbedder(model, runner).embed(texts)` runs `llama-embedding` once per batch, with:
    - Qwen3's prefix on every text;
    - texts as one argument, never a file;
    - a 10 s timeout;
    - the array output parsed, with the count checked.
  - `embedder_from_env()` returns `(embedder, "")`, or `(None, why)` when `llama-embedding` or the model (`LERNI_EMBED_MODEL`, default `~/.lerni/models/Qwen3-Embedding-0.6B-Q8_0.gguf`) is missing, as `mac_speech_from_env` does.
- **The checks (`src/lerni/student/meaning.py`, new, standard library only):**
  - `Embedder` (the protocol) and the cut-offs: `ASIDE = 0.55`, `REPEAT = 0.91`, `GOALS_WIN = 0.80`.
  - `skipped(m, embedder) -> frozenset[str]`: removed names at `GOALS_WIN` or more with an active goal's name or an area that has goals.
  - `Meaning.build(embedder, texts)` makes one call. Then:
    - `repeat(idea, against)`: at `REPEAT` or more with any of `against`;
    - `aside(text, goal, removed)`: at `ASIDE` or more with a removed name, and more than with `goal`;
    - a text with no vector never matches.
  - Counters for the log line.
- **The race (`race.py`):**
  - **A race view of the map:** `race_view(m, skip)` is the map with skipped names taken off its removed list, kept in memory only.
    - `RaceDesk._map(username)` gives it, using the skip names saved at the last write (`self._skip`, names only), and race code reads every map through it. So `fits`, the start and prefill re-checks, `_take_bonus`, `_due`, and `quiz_input`'s "Set aside, never use" line all honor the skip with no new parameters.
    - Chat's map block reads the real map, so a skipped name still steers Chat away.
  - **`_write`:**
    - before the first try, `skipped` (one call, only when the map has removed names);
    - on each try, one `Meaning.build` over that try's question texts and ideas, bonus questions, the removed names, the goal names, the recent ideas, and the ideas kept so far, passed to `check_questions` and `check_bonus`;
    - after each try, one log line, numbers only ("by meaning: 2 repeats, 0 set-aside").
  - **`check_questions` and `check_bonus`** gain `meaning=None` and `due=()`:
    - a repeat by meaning goes to `spare`, like a repeat in the same words;
    - a set-aside by meaning is dropped;
    - an idea that `_same_idea`s a due one skips the repeat check.
  - **`RaceDesk(embedder=None)`:** with none, or when a call fails, every check is word-only, as today, and a race never waits on it. The checks never run under `self._lock`.
- **Wiring:**
  - `app.py` passes `embedder_from_env()`'s embedder to the race desk.
  - `serve.py` prints `Race checks by meaning: on` or `off (<why>)` beside the voice line.
  - `lerni service install` warns when `llama-embedding` isn't on the saved PATH.

No screen changes, so there's no mockup. A question write gets up to about 4.5 s longer (three calls at most). Writes run ahead in the background, so the student rarely waits on it.

## Tests (minimal, fakes only)

`tests/student/test_meaning.py`, with a fake embedder (vectors from words, plus pairs set by hand):
- **The happy path:** a write drops a near-repeat of a recent idea (into spare) and a question near a removed name. A removed "math" interest beside a Math goal is skipped: its questions race, and it's off the "Set aside" line.
- **Safety:** an embedder that raises leaves the word match deciding, and the race is written.
- **Safety:** an idea due for review stays when it's within the cut of a recent idea.
- **The adapter:** a fake runner's array output is parsed in order, the texts are in one argument, and the wrong count is refused.

No prompt changes, so no eval. By hand: rerun `scripts/bakeoff_embeddings.py`, and a throwaway server's race writes print the log line.

## Deploying

Safe to put on the home server while in use: pull, reinstall, restart (a restart clears open conversations). The model is already in `~/.lerni/models/` on the home server, and `llama-embedding` is on the server's saved PATH beside `whisper-cli`, so nothing else is needed. The start-up lines say whether checks by meaning are on. To turn them off, rename the model file and restart.
