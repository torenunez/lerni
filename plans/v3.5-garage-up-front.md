# v3.5 The garage up front: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The garage is the first thing in Games and is simple enough for any age:
- your car, big, with a next-goal bar;
- My cars and Showroom always open, as tiles;
- speed as ⚡ to ⚡⚡⚡⚡⚡ (no decimals anywhere on screen);
- a dollar price with a family-car comparison;
- the technical facts tucked under "Car facts".

**Architecture:**
- **`garage.py`** gains three plain helpers: `bolts(c)` (1–5 from the car's boost), `family_cars(usd)` (the comparison line), and `next_goal(cars, owned, balance)` (the car to save for).
- **`race.py`:** `Race` remembers its car, so changing cars mid-race changes nothing on the track.
- **`web/games.py`** rebuilds the tab:
  - a **hero** (the car you're driving, or the race in progress);
  - **Race!**;
  - **My cars** and **Showroom** as two tile grids.

  Every car gets one tile in each grid, shown or hidden by ownership, because Gradio builds components once at startup.
- **The track** is scaled to each car's perfect run, so the finish is reached only on the fifth answer.

**Tech Stack:** Python 3.11+, Gradio 6.30, pytest.

**Spec:** [spec 09](specs/09-play-and-points.md) (Games, the garage, the Numbers table), as changed by the admin on 2026-10-13. Their decisions:
- the garage at the top of Games;
- ⚡ bolts instead of the gas multiplier;
- the dollar price with a family-car comparison;
- "the decimal gas boost is too complicated".

## Global Constraints

- **No decimals on screen** in the garage or race: no "×1.29", no "2.4 s" outside Car facts. Car facts may show the 0–60 seconds; that's a real fact.
- **⚡ count** = 1 + round((boost − 1) ÷ 0.4 × 4), so 1 to 5. The race maths (`boost`) doesn't change.
- **Family car** = $50,000. Under $75,000: "about the price of a family car". Otherwise "as much as N family cars 🚗", with N = round(usd ÷ 50,000) and a thousands comma.
- **Next goal:** the cheapest car sold to them that they don't own and can't afford yet.
  - It shows "⭐ balance / price" and "about N races", with N = ceil(gap ÷ 13).
  - If every unowned car is affordable: "You can get the <name> now!"
  - If they own every car: "Every car is yours! 🏆".
- **Prices** stay as v3.4 made them: dollars ÷ 2,500, rounded to tens, at least 10.
- **Buttons** are at least 48 px tall with 16 px text. A car they can't afford shows "N more ⭐" on a button that can't be tapped. Numbers use thousands commas.
- **Phone first** (rule 9): tiles are 2 across on a phone and 3–4 across on an iPad, with no sideways scroll. Check at 375 × 812 with the browser's keyboard closed. There's no text field in Games.
- **Nothing private in the repo:** tests and docs use made-up cars and numbers.
- **Tests (rule 4):** one happy-path test for the new helpers, and one regression test for the finish line. Fakes only.

## Review Focus

```python
FAMILY_CAR_USD = 50_000  # about what a new family car costs
STARS_PER_RACE = 13  # about what a race earns, for "about N races"


def bolts(c: Car) -> int:
    """How fast a car feels, as 1 to 5 ⚡, from its gas boost."""
    return 1 + round((boost(c) - 1) / (MAX_BOOST - 1) * 4)


def family_cars(usd: int) -> str:
    """A price anyone can picture; "" for a car with no price in dollars."""
    if usd <= 0:
        return ""
    if usd < FAMILY_CAR_USD * 1.5:
        return "about the price of a family car"
    return f"as much as {round(usd / FAMILY_CAR_USD):,} family cars 🚗"


def next_goal(cars: Sequence[Car], owned: Collection[str], balance: int) -> tuple[Car | None, str]:
    """The car to save for next, and the line that says how far off it is."""
    wanted = sorted((c for c in cars if c.id not in owned), key=lambda c: c.price)
    if not wanted:
        return None, "Every car is yours! 🏆"
    later = [c for c in wanted if c.price > balance]
    if not later:
        return wanted[-1], f"You can get the {wanted[-1].name} now!"
    goal = later[0]
    races = math.ceil((goal.price - balance) / STARS_PER_RACE)
    return goal, f"{goal.name} · ⭐ {balance:,} / {goal.price:,} · about {races} races"
```

```python
def card_html(c: Car, owned: bool = False) -> str:
    """One tile: the picture, the name, ⚡, the price (for sale only), and Car facts."""
    pic = (f'<img src="/cars/{c.id}" alt="{html.escape(c.name)}">' if c.picture
           else car_card_svg(c.id))
    zap = f'<span class="lerni-zap" aria-label="speed {bolts(c)} of 5">{"⚡" * bolts(c)}</span>'
    price = ""
    if not owned and c.price:
        price = f'<span class="lerni-usd">${c.usd:,}</span>' if c.usd else ""
        price += f'<span class="lerni-like">{family_cars(c.usd)}</span>' if c.usd else ""
    facts = [f"{label}: {html.escape(v)}" for label, v in (
        ("Engine", c.engine), ("Power", f"{c.power_hp:,} hp" if c.power_hp else ""),
        ("Drive", c.drive), ("0–60 mph", f"{c.zero_to_60:g} seconds" if c.zero_to_60 else ""),
        ("", c.note)) if v]
    if c.usd:
        facts.append(f"${c.usd:,} ÷ $2,500 a ⭐ ≈ {c.price:,} ⭐")
    facts.append("More ⚡ moves your car farther with each right answer.")
    details = ("<details><summary>Car facts</summary>"
               + "".join(f"<div>{f.removeprefix(': ')}</div>" for f in facts) + "</details>")
    return (f'<div class="lerni-card">{pic}<b>{html.escape(c.name)}</b>{zap}{price}'
            f"{details}</div>")
```
