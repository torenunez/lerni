# v3.18 Pitched right: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Race questions get harder or easier per goal, so the student gets about half to three quarters right. Since their first car upgrade, they've been at about 84%.

**Architecture:**
- **Levels on disk (`concepts.py`):**
  - **The concept file:** becomes schema 3, `{"schema": 3, "concepts": [...], "levels": {goal_id: {"level": n, "right": r, "asked": a}}}`.
    - `right` and `asked` count the goal's answers since its level last changed.
    - Goal ids and numbers only.
    - Schema 2 and v3.9 files load with every goal at 3.
  - **Keeping both parts:** `_read()` returns the whole file, and `_change` writes the concepts and levels together, so neither part loses the other.
  - **Constants:**
    - `START_LEVEL = 3` (today's questions);
    - levels run from `MIN_LEVEL = 1` to `MAX_LEVEL = 5`;
    - `LEVEL_WINDOW = 5` answers per check;
    - `UP_AT = 4` (4 or 5 right goes one harder);
    - `DOWN_AT = 2` (2 or fewer goes one easier).
  - **The calls:**
    - `levels(username) -> dict[str, int]`;
    - `practiced(username, goal_id, right)`: counts one answer, and at 5 answers moves the level by the rule and starts the count again. An empty `goal_id` (a goal gone from the map) is ignored.
- **The race (`race.py`):**
  - **The hook:** `RaceDesk.pick` calls `concepts.practiced` beside `concepts.answered`, with the goal's id from the map (as `_log` finds it), best effort (an `OSError` never stops a race).
  - **The prompt:** `quiz_input(m, today, supervised, recent, levels={})` writes each goal as `- Fractions (level 4; notes: halves and quarters)`.
    - **Why that shape:** `check_questions` already cuts `goal` at " (", so a copied level or note never breaks the match.
    - **Default:** a goal with no level is shown at 3.
  - **`QUIZ_SYSTEM`:** one rule: "Pitch each goal's questions at its level:", then the five levels from spec 09b, in short lines:
    1. one step, in the goal's own words; wrong choices clearly off;
    2. one step in a new setting;
    3. apply it to one of their interests; wrong choices plausible;
    4. two steps, or a comparison; wrong choices are common mistakes;
    5. a what-if, or work back from an answer; wrong choices are near misses.
  - **Wiring:** `_write` passes `self.concepts.levels(username)`.
  - **Held questions:** written ahead at the old level, they race as they are (a level change shows from the next set).
- **Never shown:** no screen shows a level. MentalMaps shows only this week's right answers, as today.

**Tech Stack:** Python 3.11+ standard library, pytest; `scripts/eval_race.py` (real Claude calls, run by hand).

**Spec:** [spec 09b](specs/09b-harder-races.md), "Levels". The admin's decisions of 2026-10-19 (aim for 50–75% right, a level per goal, never shown) and of 2026-10-20 (this goes first, before the map journal).

## Global Constraints

- **Rule 6:** the concept file holds goal ids, labels, dates, and numbers; never question text.
- **Rule 5:** levels never touch the map.
- **Tests:** one new test, `test_race.py`, `test_a_goals_level_follows_its_last_five_answers`:
  - through `RaceDesk.pick`, 4 right of 5 raises Fractions to level 4;
  - a schema 2 file keeps its concepts after the first level write;
  - 5 more answers with 2 right lower it to 3;
  - `quiz_input` shows "Fractions (level 4" when the level is 4.
- **Eval:** one case in `eval_race.py`: the same goal at level 1 and at level 5. It prints both sets for the admin to compare; level 5's should be visibly harder (a judgment, printed, not asserted). Run by hand once.

## Review Focus

1. **Upgrading a schema 2 concept file:** its concepts survive the first level write, and older code reading a schema 3 file still finds `concepts`. A rollback keeps working, because v3.17's `ledger()` reads only `concepts`.
2. **Two answers at once** (a double tap is dropped already), and the concept lock covers `practiced`.
3. **A goal renamed** (the id stays, so the level stays), **removed and put back** (the id stays), or **deleted** (its level entry is never read again).
4. **An educator's own races** move only their own levels.
5. **Claude copying the level into `goal`:** the cut at " (" keeps it matching; a test asserts the line's shape.
