# v3.39: spec 10, local embeddings

**Goal:** Spec 10 decides how Lerni compares ideas by meaning on the home server: the model (chosen by a measured bake-off), the adapter, the two uses v3.40 builds, and the thresholds.

**Why (the admin, 2026-11-03 and 2026-11-09):** "when are we going to use embeddings?" Word matching misses the same idea in other words. A removed "guns" catches "gun" but not "rifles", and "0–60 vs top speed" and "how fast cars speed up" count as two ideas, so near-repeats get through. The admin picked these two uses first. Most of what the student says is English, with some Spanish.

**What today's data says:** the student's map has 49 items, none resting, and 4 set aside. The tagger already reads every active item, so the "same as" shortlist does nothing until items rest. Spec 10 keeps it, and the other uses, as later work.

## What v3.39 delivers

Docs and one script. No app code changes, so there's no mockup.

- **`scripts/data/embedding_pairs.jsonl` (new, public):** about 100 made-up labelled pairs on generic topics, never taken from a real map. About 90 are English and 10 are Spanish or cross-language ("sharks" and "tiburones").
  - **`set_aside`:** about 50 pairs of a removed name and a question's text and idea. The label is `close` when the text is about the removed topic or a kind of it ("guns" and "a rifle's range"), and `far` otherwise ("guns" and "a water pistol's spray"; "sharks" and "how whales breathe").
  - **`repeat`:** about 50 pairs of a recent idea label and a new one on the same goal. The label is `same` for the same idea in new words, and `different` for a new angle. The hard cases are deliberate: "0–60 acceleration" and "top speed".
- **`scripts/bakeoff_embeddings.py` (new, run by hand like the evals):**
  - For each candidate model in `~/.lerni/models/`, it embeds every pair through `llama-embedding`, adding the model's own prompt prefix (e5's `query: `, nomic's `search_query: `, EmbeddingGemma's prompt).
  - It prints, for each use:
    - ROC AUC;
    - the threshold that keeps false matches to about 1 in 10 for `set_aside`;
    - the threshold that keeps them to about 1 in 20 for `repeat`;
    - the recall at that threshold;
    - English and Spanish pairs, also shown separately.
  - It also times one call of 60 short texts, including the model load.
- **Candidates:**

  | Kind | Model | Size (about) |
  |---|---|---|
  | English | all-MiniLM-L6-v2 | 25 MB |
  | English | bge-small-en-v1.5 | 35 MB |
  | English | nomic-embed-text-v1.5 | 140 MB |
  | Multilingual | multilingual-e5-small | 120 MB |
  | Multilingual | EmbeddingGemma-300m | 330 MB |
  | Multilingual | Qwen3-Embedding-0.6B | 640 MB |

  They come from Hugging Face as GGUF files. I ask before each download, giving the file name, source, and exact size. Models that aren't downloaded are skipped.
- **The pick:** the best mean AUC across both uses, with Spanish no worse than 0.05 below English, and one call of 60 texts under 2 s on the M4. A tie goes to the smaller model.
- **A private check, never saved:** the chosen model runs on the real map's set-aside names and the last two weeks of race idea labels. It shows what the thresholds would have dropped, printed here only and never written to a file or the repo.

## Spec 10 (`plans/specs/10-local-embeddings.md`), the decisions it records

- **The adapter (rule 3):**
  - **The contract:** `Embedder.embed(texts) -> list[list[float]]` (unit vectors).
  - **The real one:** `LlamaEmbedder` runs `llama-embedding -m MODEL --embd-output-format array -p "<texts joined by a separator>"` as one call per batch. Texts go as an argument, never to a file. It has a timeout.
  - **The model:** it comes from `LERNI_EMBED_MODEL`, defaulting to the chosen file in `~/.lerni/models/`.
  - **Tests:** a fake that builds vectors from words, so tests never run a model.
  - **Setup:** `lerni service install` warns when the tool or model is missing, as it does for `whisper-cli`.
- **Off means today:** with no tool, no model, a timeout, or a bad answer, Lerni uses the word match only and logs one line (numbers only). It never blocks a race.
- **Use 1, set-aside by meaning:** wherever race code calls `mentions_set_aside` (questions, bonus questions, probe topics, why lines), each check also embeds, in one call:
  - the map's removed names;
  - each candidate's question, idea, and key ideas.

  A candidate within the `set_aside` threshold of any removed name is dropped. This runs beside the word match, never instead of it.
- **Use 2, repeats by meaning:** a new question's idea label is compared with:
  - the recent ideas Claude was told to avoid;
  - the other ideas in the same set.

  One too close to any of them is dropped, like today's exact repeats. Ideas due for review are never dropped, because they're meant to come back.
- **Thresholds:** constants from the bake-off, named in the spec with the measured recall and false-match rates.
- **What's kept:** no vectors on disk, and no cache. Idea labels and names are embedded fresh at each check: one call per question set, next to a 25–30 s question write. Rule 6 is unchanged. A cache comes only if a later use needs one.
- **Later uses, described but not built:**
  - Chat's goals ranked by the student's message;
  - the "same as" shortlist for resting items;
  - Version 5 suggestions that never repeat a goal already there;
  - grouping near-duplicate ideas in `lerni stats`.
- **Spec 08's "no embeddings"** is lifted for these uses only.
- **v3.40's tests:**
  - the happy path: the fake drops a near-repeat and a set-aside match;
  - safety: a failing embedder falls back to the word match;
  - safety: an idea due for review is kept.
