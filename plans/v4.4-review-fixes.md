# v4.4: review fixes (from the v4.3 review and the admin's example)

**Goal:** close the v4.3 review's findings before the checked bank (v4.5) builds on them.

**Why:**
- **A fresh review of v4.3** found one important bug and a few small ones.
- **The admin's example:** an "odd one out" question built from the parts of an equation, a dealt format forced onto a goal it doesn't fit.

No screen changes, so there's no mockup.

## Fixes

1. **The same review twice in a race (important):**
   - **What happens today:** a question on a review that goes to spare already carries the review's label. If the race runs short, the spare fill can ask that review a second time, and both answers move it.
   - **The fix:** a spare keeps Claude's own label, and the spare fill skips any idea already in the race on that goal.
2. **A restore that stops halfway:** `_keep_sign_ins` skips an account whose session version isn't a number, instead of stopping the restore with the server down.
3. **Minus signs:**
   - **Where a minus stays a sign:** after `<`, `>`, `+`, `*`, `/`, `^`, `%`, `,`, `(`, `[`, or `=`, so `x<-3` isn't `x<3`.
   - **Also kept:** a minus before a letter (`−x`), and `^` as a sign.
4. **Old duplicates:** `ConceptStore.due()` lists each idea once, by goal and its normalized label, so two old spellings of one idea don't fill two review slots.
5. **A refused tick:** a goal suggestion refused because its notes changed leaves the list right away, with no 14-day block.
6. **One read per change:** `ConceptStore._change` reads the file once, not three times.
7. **`fsync`:** on macOS, `F_FULLFSYNC` flushes the drive's cache too.
8. **Formats that don't fit:** `QUIZ_SYSTEM` says that when a planned format can't make a sensible question for its goal, Claude uses "how it works" instead and names that in `format`.
9. **The car eval:** the comparison case passes with no comparison, since "at most 1" allows none. It still fails when a question names one car's facts wrong.
