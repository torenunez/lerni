# v3.10 Map fixes and long-term memory: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix four map and race bugs found in review, and stop Lerni forgetting over months.
- **The bugs:**
  - a set-aside lifted on load;
  - a race start that skips a fresh map check;
  - "es" plurals merging unrelated words;
  - the map block cut mid-line.
- **Why memory matters:** the supervised student's map has 30 items after 9 days. At 60 it's full, and today each new interest then deletes the least-seen one, history and all.

**Architecture:**
- **Map fixes (`interests.py`, `race.py`):**
  - **Set-asides on load:** loading heals a set-aside only next to a near-name *goal*. Next to a near-name *interest*, the set-aside stays and that interest goes.
  - **A race start rechecks:** after `start` writes questions, it reads the map again and filters with `fits`. If fewer than 5 are left, it refuses before the race is counted.
  - **Plurals:** a plural "es" only after s, x, z, ch or sh. A short list of words that end in "s" but aren't plurals ("news", "series", "species", "physics", "gas", "bus", "glass", …). Words ending in "ss", "us" or "is" never lose their "s".
  - **The map block:** it adds whole lines in priority order while they fit in 1,500 characters, so it never cuts one mid-way.
- **The archive (`interests.py`):**
  - **When the map is full:** `make_room` moves the least-seen interest to `InterestMap.archived`, keeping its name, days and mentions, instead of deleting it.
  - **How it comes back:** when the tagger or a person names it again, it returns with its history plus today. That may archive another.
  - **What's left out:** archived items aren't in the prompt, the picture, or races.
  - **On screen:** both MentalMap lists show a read-only "Resting (N)" section, like "Removed (N)": each name with its day count, and a line saying it comes back when mentioned.
  - **No cap:** names only, so a few hundred over years.
- **The concept ledger (`concepts.py`):**
  - **What it keeps:** every concept ever asked, for good: `concept`, `goal`, `first`, `last`, `asked`, `right`.
  - **"Asked lately":** `recent()` is now a view of the ledger: last asked within 14 days, newest first, at most 40.
  - **Counting:** `RaceDesk.pick` counts right answers per concept, best effort, as `add` already is.
  - **Old files:** the v3.9 `recent` list loads into the ledger.
- **Logs kept 1 year (`logs.py`, `lerni logs`):**
  - `KEEP_DAYS = 365`.
  - `lerni logs` shows the last 7 days by default; `--days N` shows more.
  - **Rule 6 changes (the admin's decision, 2026-10-19):** conversation text is kept in the logs for 1 year while Lerni is family-hosted. Shorten it before anyone outside the family uses it.

**Tech Stack:** Python 3.11+ standard library, Gradio 6.30 (`gr.render`, already in use), pytest.

## Global Constraints

- **Only people set goals (rule 5):** the archive and the ledger never create or change a goal.
  - A goal is never archived. As today, a map full of goals and groups refuses a new interest.
- **Set-asides win:** an archived name that a person sets aside is no longer brought back by the tagger. Never re-add anything set aside, from the archive or otherwise.
- **Rule 6 after this:**
  - message text appears only in the logs (now 1 year);
  - the concept ledger holds labels and numbers, never question text;
  - the archive holds names, days and counts.
- **Old files load:**
  - maps without `archived`;
  - v3.9 concept files;
  - logs older than 7 days (now kept).
- **Tests:** a regression test per bug, plus one each for the archive and the ledger (CLAUDE.md rule 4).

## Review Focus

1. **A map with groups is full:** a group with kinds is never archived (same rule as today), and an archived kind loses its `kind_of` link. When it comes back, the tagger may group it again.
2. **A person removes an item whose name is in the archive** (for example re-added by hand, then removed): removed wins, and the archived copy is dropped.
3. **Put back and Delete for good** don't touch the archive.
4. **The near-name heal and the archive together:** an archived "guns" and a set-aside "gun" are never both active.
5. **`lerni logs` with a year of logs** stays quick to read for the default 7 days.
