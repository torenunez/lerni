# v2.17 MentalMaps list: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (chosen: Native). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make each MentalMap an editable list of goals and interests: add, remove, put back, rename, and goal notes. Tapping an item shows its strength and links, and removed interests steer Lerni away.

**Architecture:**
- **Data rules** live in `interests.py`: `removed_info`, `put_back`, `strength`, `details`, and the steer-away line in `map_block`.
- **A new `web/mentallist.py`** holds:
  - plain handler functions, checked per request through `maps._act`;
  - one `gr.render` list component, used by My MentalMap (`maps.py`) and MentalMaps (`educator.py`).
- **The rename to MentalMap** covers on-screen labels and docs only.

**Tech Stack:** Python 3.11+, Gradio 6.30 (`gr.render`), pytest.

**Spec:** [plans/specs/07-mentalmap-list.md](specs/07-mentalmap-list.md)

## Global Constraints

- **Rename:** screens and docs say **MentalMap**: "My MentalMap" and "MentalMaps". Code, tab ids (`mymap`, `maps`) and data folders keep `map`.
- **Strength,** by days in the last 30 (`FADE_DAYS`): 4 or more → strong, 2–3 → growing, 1 or none lately → faint, never → not yet. Labels: 💪 strong, 🌱 growing, 🌫️ faint, ⏳ not yet.
- **Steer-away line:** up to 8 removed **interests**, placed before "Recent bridges", inside the 1,500-character cap.
- **Old files:** maps without `removed_info` load unchanged. Their removed items come back as interests.
- **CLAUDE.md:**
  - rule 4: minimal tests;
  - rule 5: only people set goals;
  - rule 8: nothing private;
  - rule 9: phone first, 16px fields, and comments of one short line;
  - every handler resolves the viewer on the server.
- **Version:** `pyproject.toml` set to `2.17`; the voice fix becomes v2.18 and LaunchAgents v2.19.

## Review Focus

1. **Stale item id:** another device removed the item → "⚠️ That's no longer on the map.", never an error page. *(Task 3 test.)*
2. **Renaming onto a removed name:** the name must leave `removed`, or Lerni would steer away from something still on the map. *(Task 1 test.)*
3. **Put back of something not in Removed** (a double tap) → a friendly ⚠️. *(Task 3 test.)*
4. **A supervised viewer, or an educator on an independent student's map, calls a handler directly** → refused, and the map is unchanged. *(Task 3 test.)*
5. **The list's render takes no `gr.Request`,** so whose map it shows must come from a server-side `gr.State` that only checked handlers set, never from a page value. *(Task 4 wiring; checked in review.)*

## Rulings made while planning

- **Spec deviation:** MentalMaps' 30-second timer keeps redrawing the **picture** only. The list redraws on its own edits, on a chat **Add**, on opening the tab, and on picking a student. A timed re-render would wipe a half-typed rename. *Cost if wrong:* the educator sees the tagger's new days only after an action or on reopening.
- **Removed:** `map_words` (the word list) and My map's two panels, replaced by the list. Also the dead `mine=False` branch of `map_tab`, since only My map uses it now.

```python
STRENGTH_LABELS = {"strong": "💪 strong", "growing": "🌱 growing", "faint": "🌫️ faint",
                   "not yet": "⏳ not yet"}


def put_back(m: InterestMap, name: str) -> Entry:
    """A person puts a removed item back, as the kind it was (older removals: an interest).

    Raises:
        MapError: Not in Removed, or no room.
    """
    found = next((r for r in m.removed if r.casefold() == name.strip().casefold()), None)
    if found is None:
        raise MapError("That isn't in Removed any more.")
    info = m.removed_info.get(found.casefold(), {})
    if info.get("kind") == "goal":
        return add_goal(m, found, info.get("notes", ""))
    return add_interest(m, found)


def strength(entry: Entry, today: date) -> str:
    """How alive an item is, from the days it came up in the last 30."""
    if not entry.days:
        return "not yet"
    cutoff = (today - timedelta(days=FADE_DAYS)).isoformat()
    recent = sum(d >= cutoff for d in entry.days)
    return "strong" if recent >= 4 else "growing" if recent >= 2 else "faint"


@dataclass(frozen=True)
class Details:
    """What tapping an item shows."""

    entry: Entry
    strength: str
    days: int
    last: str  # ISO date, "" if never
    explained: int
    resting: bool  # Lerni is giving this goal a rest
    bridges: list[tuple[str, str]]  # (id, name) at the other end
    related: list[tuple[str, str]]


def details(m: InterestMap, entry_id: str, today: date) -> Details:
    """The facts about one item.

    Raises:
        MapError: No such entry.
    """
    e = m.get(entry_id)
    names = {x.id: x.name for x in m.entries}

    def ends(kind: str) -> list[tuple[str, str]]:
        other = [k.b if k.a == e.id else k.a for k in m.links if k.kind == kind and e.id in (k.a, k.b)]
        return [(i, names[i]) for i in dict.fromkeys(other) if i in names]

    return Details(e, strength(e, today), len(e.days), e.days[-1] if e.days else "",
                   len(e.explained), e.kind == "goal" and backed_off(e, today),
                   ends("bridge"), ends("related"))
```

```python
def add_item(maps, students, viewer, requested, kind: str, name: str, notes: str) -> str:
    """Add a goal or an interest to a MentalMap this viewer may edit."""
    if kind == "Goal":
        return _act(maps, students, viewer, requested, lambda m: add_goal(m, name, notes),
                    "Goal added.")
    return _act(maps, students, viewer, requested, lambda m: add_interest(m, name),
                "Interest added.")


def remove_item(maps, students, viewer, requested, entry_id: str) -> str:
    """Remove an item; it waits in Removed, and Lerni steers away from a removed interest."""
    return _act(maps, students, viewer, requested, lambda m: remove(m, entry_id or ""),
                "Removed. Put it back from Removed any time.")


def put_back_item(maps, students, viewer, requested, name: str) -> str:
    """Put a removed item back."""
    return _act(maps, students, viewer, requested, lambda m: put_back(m, name or ""),
                "Put back.")


def rename_item(maps, students, viewer, requested, entry_id: str, name: str) -> str:
    """Rename an item."""
    return _act(maps, students, viewer, requested, lambda m: rename(m, entry_id or "", name),
                "Renamed.")


def save_notes(maps, students, viewer, requested, entry_id: str, notes: str) -> str:
    """Save a goal's notes for Lerni."""
    return _act(maps, students, viewer, requested, lambda m: set_notes(m, entry_id or "", notes),
                "Notes saved.")
```

```python
def mental_list(signin, students, maps, owner, requested, version) -> None:
    """The add form, then 🎯 Goals and 💚 Interests as rows to open, rename, or remove."""
    opened = gr.State(None)  # the open item's id
    with gr.Row(elem_classes="lerni-add"):
        kind = gr.Radio(["Goal", "Interest"], value="Goal", show_label=False, scale=0)
        name = gr.Textbox(show_label=False, placeholder="Name", max_length=MAX_NAME, scale=2)
        notes = gr.Textbox(show_label=False, placeholder="Notes for Lerni (goals)",
                           max_length=MAX_NOTES, scale=2)
        add = gr.Button("Add", variant="primary", scale=0, min_width=70)
    status = gr.Markdown()

    def run(action, *args, request: gr.Request):  # every edit re-checks who's asking
        return action(maps, students, signin.viewer(request.username), *args)

    def on_add(k, n, t, req, v, request: gr.Request):
        message = run(add_item, req, k, n, t, request=request)
        ok = message.startswith("✅")
        return [message, *cleared(2, ok), v + ok]

    add.click(on_add, [kind, name, notes, requested, version],
              [status, name, notes, version], **PRIVATE)

    def wire(e_id: str, row, trash, rename_box=None, rename_btn=None, notes_box=None,
             notes_btn=None) -> None:
        """One item's events; each returns [status, version]."""
        def done(message: str, v: int) -> list[Any]:
            return [message, v + message.startswith("✅")]

        def on_remove(req, v, request: gr.Request):
            return done(run(remove_item, req, e_id, request=request), v)

        trash.click(on_remove, [requested, version], [status, version], **PRIVATE)
        row.click(lambda o: None if o == e_id else e_id, opened, opened, **PRIVATE)
        if rename_btn is not None:
            def on_rename(new, req, v, request: gr.Request):
                return done(run(rename_item, req, e_id, new, request=request), v)
            rename_btn.click(on_rename, [rename_box, requested, version], [status, version],
                             **PRIVATE)
        if notes_btn is not None:
            def on_notes(text, req, v, request: gr.Request):
                return done(run(save_notes, req, e_id, text, request=request), v)
            notes_btn.click(on_notes, [notes_box, requested, version], [status, version],
                            **PRIVATE)

    @gr.render(inputs=[owner, version, opened])
    def draw(who: str, _v: int, open_id: str | None) -> None:
        if not who:
            gr.Markdown("Pick a student.")
            return
        m, today = maps.get(who), date.today()
        for title, kind_ in (("🎯 Goals", "goal"), ("💚 Interests", "interest")):
            items = [e for e in m.entries if e.kind == kind_]
            gr.Markdown(f"**{title}**" + ("" if items else ": none yet"))
            for e in items:
                with gr.Row(elem_classes="lerni-item"):
                    label = f"{e.name} · {STRENGTH_LABELS[strength(e, today)]}"
                    row = gr.Button(label, scale=1, key=f"open-{e.id}")
                    trash = gr.Button("🗑", scale=0, min_width=48, key=f"rm-{e.id}")
                if open_id != e.id:
                    wire(e.id, row, trash)
                    continue
                d = details(m, e.id, today)  # the open item's facts and edits
                facts = [STRENGTH_LABELS[d.strength],
                         f"came up on {d.days} day{'s' * (d.days != 1)}"
                         + (f", last on {d.last}" if d.last else "")]
                if e.kind == "goal":
                    facts.append(f"explained on {d.explained} day{'s' * (d.explained != 1)} "
                                 "(Lerni's guess)")
                    facts += ["Lerni is giving it a rest"] if d.resting else []
                gr.Markdown(" · ".join(facts), key=f"facts-{e.id}")
                notes_box = notes_btn = None
                if e.kind == "goal":
                    notes_box = gr.Textbox(e.notes, label="Notes for Lerni",
                                           max_length=MAX_NOTES, key=f"notes-{e.id}")
                    notes_btn = gr.Button("Save notes", size="sm", key=f"save-{e.id}")
                rename_box = gr.Textbox(e.name, label="Name", max_length=MAX_NAME,
                                        key=f"name-{e.id}")
                rename_btn = gr.Button("Rename", size="sm", key=f"ren-{e.id}")
                wire(e.id, row, trash, rename_box, rename_btn, notes_box, notes_btn)
                for title_, ends in (("Bridges", d.bridges), ("Related", d.related)):
                    if ends:
                        gr.Markdown(f"**{title_}**", key=f"{title_}-{e.id}")
                        for other_id, other in ends:
                            jump = gr.Button(f"→ {other}", size="sm", key=f"j-{e.id}-{other_id}")
                            jump.click(lambda i=other_id: i, None, opened, **PRIVATE)
        if m.removed:
            with gr.Accordion(f"Removed ({len(m.removed)})", open=False):
                for r in m.removed:
                    with gr.Row(elem_classes="lerni-item"):
                        gr.Markdown(r, key=f"gone-{r}")
                        back = gr.Button("Put back", size="sm", scale=0, key=f"back-{r}")

                    def on_back(req, v, request: gr.Request, r=r):
                        message = run(put_back_item, req, r, request=request)
                        return [message, v + message.startswith("✅")]

                    back.click(on_back, [requested, version], [status, version], **PRIVATE)
```
