# v3.25 The educator's page: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Suggesting a goal for the student is quick: sign in, type an idea, Send, Add.

**Today:**
1. pick the student every time;
2. scroll past the map and about 37 list rows to the chat at the bottom;
3. type while the iPhone keyboard moves the page;
4. tick each suggestion;
5. tap Add.

**The admin's decisions (2026-10-23):**
- layout A from the mockups: a Suggest box at the top;
- suggestions arrive already ticked;
- Students and My account become one **Settings** section;
- the screens are shaped around the one supervised student.

**Architecture:**
- **The menu (`web/main.py`):**
  - **For an educator:** Chat · Games · My MentalMap · **the student's display name** · Settings.
  - **The student's entry** is the existing `maps` tab. Its label comes from the account when the educator has exactly one supervised student, and reads "MentalMaps" otherwise.
  - **The name** is set on load, together with the screen title. It's never written in code.
  - **Opening section:** an educator with a supervised student starts on the student's page; everyone else as today.
- **Settings (`web/accounts.py`, `web/main.py`):**
  - **One tab, id `account`, labelled "Settings",** for every independent account: *Your account* (display name, password) first, then *Students* (the table, Add a student, Reset a password or archive), shown only to educators.
  - **The `students` tab goes away;** its handlers move into Settings unchanged, with the same role checks.
- **The student's page (`web/educator.py`), top to bottom:**
  1. **The picker:**
     - with one supervised student, picked for you and hidden;
     - with more, the dropdown, which remembers the last pick on the device.
  2. **⭐, cars, and this week's line,** as today.
  3. **Suggest a goal:** a one-line box (16 px, Enter sends), 📎 to attach notes, and Send. It goes to the same MentalMaps chat agent as today.
  4. **Lerni's reply line and its suggestions,** **all ticked**, with one button: "Add N goals". Unticking updates the count. Nothing is added until the tap (rule 5).
  5. **The map picture.**
  6. **The list (`mental_list(…, folded=True)`):**
     - the add form;
     - **Goals (20)** and **Interests (17)** as closed accordions;
     - Removed and Older interests as today.

     My MentalMap keeps its lists open (`folded=False`, the default).
  7. **"Conversation with Lerni"** at the bottom, a closed accordion with the full chat history.
- **The iPhone keyboard:** with the box at the top, opening the keyboard no longer pushes the page. Moving the box should be enough, and the admin confirms on the phone (rule 9).

**Tech Stack:** Gradio 6.30 (`gr.Accordion`, `gr.render` existing), pytest.

**Spec:**
- the educator PRD's "See the map" and "Set goals" stories;
- [spec 06](specs/06-educator-chat.md), the MentalMaps chat (its proposals stay proposals until ticked);
- [spec 07](specs/07-mentalmap-list.md), the list.

## Global Constraints

- **Rule 5:** goals are saved only from the educator's tap on Add. Pre-ticking is a default, not a save.
- **Rule 8:** the student's name comes from the account at run time; no name in code or tests.
- **Rule 9:**
  - phone first: checked at phone size as an educator, right after a restart, with both MentalMap lists (My MentalMap open, the student's folded);
  - the admin checks the keyboard on the iPhone.
- **Roles:** every Settings and student-page handler resolves the viewer on the server, as today. A non-educator never sees Students.
- **Tests:**
  - `test_web_roles.py`'s tab test becomes: an educator sees `("games", "ask", "mymap", "maps", "account")` and opens on `maps`; others are as today;
  - a new check that the menu label is the student's display name with one supervised student and "MentalMaps" with two;
  - the existing role tests for Students keep passing from Settings.

## Review Focus

1. **Two supervised students later:** the label falls back to "MentalMaps", the picker shows, and the last pick is remembered.
2. **An educator with no supervised student** opens on Chat, and the page says how to add one in Settings.
3. **Pre-ticked suggestions:**
   - unticking all hides Add;
   - a second Send replaces the list;
   - a double tap on Add adds once.
4. **Settings for an independent student who isn't an educator:** only *Your account*.
5. **Two `gr.render` lists at once** (My MentalMap open, the student's folded), right after a restart (rule 9).
