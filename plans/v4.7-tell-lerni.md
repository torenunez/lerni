# v4.7: feedback and answer keys through Tell Lerni

**Goal:** the educator tells Lerni in their own words how questions should change, or hands it an answer key, and every question after follows. ([Educator PRD story](../docs/prd/educator.md#story-give-feedback-and-answer-keys-through-tell-lerni), [v4.0 design](v4.0-educator-chat.md))

**Why:**
- **Notes that apply to every goal have nowhere to go.** The v4.5 ratings steer one goal at a time, so a note like "more variety, fewer dinosaur questions" or "use cm" can't reach every question.
- **No way to hand Lerni a worksheet.** The educator can't yet give Lerni the questions they're teaching from.

## What the educator sees (the mockup, 2026-11-12)

Tell Lerni stays where it is. Its reply can now propose three new kinds, each ticked on arrival like goals:

| Proposal | Label | On a tick |
|---|---|---|
| **Guidance** | 🧭 All goals: use cm, not inches | Saved. Every question write and the morning plan follow it. |
| **Level** | ⬆️ Measuring length: one level harder (3 → 4) | The goal's level moves one step, then keeps adjusting from answers as today. |
| **Answer key** | 🔑 Telling time: the question · the answer · not the two wrong choices | Saved to that goal's checked bank as a good question. |

- **Guidance replaces level-style requests:** "too easy" becomes a level proposal, not a guidance note, so notes never fight the level ladder.
- **"Add to the map" becomes "Add ticked"**, since not every proposal changes the map.
- **A folded "Guidance for Lerni (n)" list** sits under the box, with the note "Read by every question and the morning plan. No names."
  - Each note shows its scope (all goals, or one goal) and can be removed.
  - In Gradio this is a tick list with a Remove button, in place of the mockup's ✕.

## The admin's calls, and mine

- **The ✗ with a why waits for v4.9.** It marks a sampled question, and the sample comes with checking a few questions. *My call, since this version has nothing to mark yet.*
- **Answer keys steer now and race later.** Saved as Good, they become examples for their goal at once (the v4.5 path); they race once banked questions race (v4.9).
- **Wrong choices come from the Tell Lerni reply itself**, so writing them costs no extra call. Lerni's small model then answers each key blind:
  - when it picks another answer, the label says so ("Lerni's check picked 6:06. Yours wins if ticked.");
  - the educator decides, and it stays ticked.
- **At most 10 guidance notes,** with the newest kept. Each is for all goals or one goal.

## Code

- **`guidance.py` (new): `GuidanceStore`, at `guidance/<user>.json`.**
  - Each note holds an id, a goal id ("" for all goals), its text (up to the notes limit), and the day it was added.
  - `add`, `remove(ids)`, and `for_goals(goal_ids)`, which returns the notes for all goals plus those goals' own notes.
  - A broken file is moved aside and never stops a race.
- **`educator_agent.py`:**
  - **New kinds:**
    - `guidance` (notes, and an optional goal name);
    - `level` (a goal name, and `harder` or `easier`);
    - `key` (a goal name, question, answer, two wrong choices, and why).
  - **Up to 8 proposals:** keys count toward the limit.
  - **What the agent sees:** the map text adds the current guidance notes and each goal's level.
  - **Parsing checks:**
    - a key needs 3 distinct short choices;
    - a level change stays within 1–5;
    - a guidance note never names something set aside.
- **`EducatorChats.ask`:** after parsing, one blind check on the small model covers all the keys in a reply, and a key it disagrees with carries a flag. If the check fails, the keys are shown without flags.
- **`apply_educator_proposals` and `educator_add`:**
  - guidance goes to `GuidanceStore.add`;
  - a level change goes to `ConceptStore.nudge_level(user, goal_id, ±1)` (new);
  - a key goes to `BankStore.add_labels` as one row, rated Good, with "from an answer key" as its note. *Built this way: no new `add_key` was needed.*
- **Race and morning plan:**
  - `quiz_input` and the morning plan's prompt gain the section "The educator's guidance:", holding the notes for all goals plus each planned goal's own;
  - a note touching anything set aside is left out.
- **`web/educator.py`:** the button label, the header line, and the folded guidance list with Remove.

## Tests (fakes only, minimal)

- **The happy path:** a fake reply proposes guidance, a level change, and a key.
  - Applying them saves the note, moves the level by one, and banks the key.
  - The next race write's prompt shows the note.
- **Safety:** nothing is saved without a tick. An unticked key leaves the bank unchanged, even when the check disagreed.
- **Safety:** a guidance note touching something set aside never reaches a prompt.
