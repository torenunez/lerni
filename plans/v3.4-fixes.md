# v3.4 Map and race fixes: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the map and race bugs found in review before the garage redesign. Nothing new appears on screen.
- A map can't be broken by Put back, a group loop, or a goal made from a group.
- A set-aside name stays out in every form: plurals, inside a race question's "why", and in questions written before it was set aside.
- Race starts are one at a time per person and never block other players.
- A bad garage file can't stop the server.

**Architecture:**
- **`interests.py`:** gets one name rule, `same_name`, and one set-aside check, `mentions_set_aside`, used by the map, the tagger and the race.
- **`interests.py` group rules:**
  - Put back and goal conversion go through the same checks as a person's edits.
  - A map loaded from disk drops links whose ends are gone.
  - The group-depth count can't loop.
- **`race.py`:** `RaceDesk.start` holds a per-person lock for the whole start. Held questions are checked again against the current map. Prefill stops once the day's races are used.
- **`web/`:**
  - The Games buttons get the conversation's concurrency limit.
  - An unexpected start error shows the "track needs a minute" line.
  - The Delete-for-good confirm is tied to the student it was tapped for.

**Tech Stack:** Python 3.11+, Gradio 6.30, pytest.

**Spec:** [spec 08](specs/08-kind-of.md) (group rules: at most 2 groups, 3 levels, no loops, interests only) and [spec 09](specs/09-play-and-points.md) (race questions never use anything set aside; the day's 10 races). Requirements this plan adds are in the to-do's v3.4 row.

## Global Constraints

- **Group rules (spec 08):** only interests go in groups; at most 2 groups per item and 3 levels; no loops. A person's "Not under" is remembered.
- **Removed names are never re-added by the tagger** (CLAUDE.md rule 5 and the map's rules); a person adding or renaming to a removed name takes it off Removed.
- **Set aside means everywhere:** no race question, choice, or "why" shown to the student mentions a removed name.
- **Only people set goals;** nothing here changes who can.
- **Tests (rule 4):** a regression test per bug fixed, no more. Fakes only; no real Claude calls.
- **Comments:** short, one line at most. No new files, so the code manifest is unchanged.

```python
def same_name(a: str, b: str) -> bool:
    """Whether two names are one, ignoring case and a plural "s" or "es" (car, cars, buses)."""
    a, b = a.strip().casefold(), b.strip().casefold()
    if a == b:
        return True
    short, long = sorted((a, b), key=len)
    return len(short) >= 3 and long in (short + "s", short + "es")  # never "pi" and "pies"


def mentions_set_aside(m: InterestMap, text: str) -> bool:
    """Whether ``text`` names anything removed from the map, as whole words, plurals included."""
    folded = text.casefold()
    for name in m.removed:
        n = re.escape(name.strip().casefold())
        if re.search(rf"(?<!\w){n}(?:e?s)?(?!\w)", folded):
            return True
        singles = [n[:-2]] if n.endswith("es") else []
        singles += [n[:-1]] if n.endswith("s") else []
        if any(len(s) >= 3 and re.search(rf"(?<!\w){s}(?!\w)", folded) for s in singles):
            return True  # "guns" set aside: "gun" too
    return False
```

```python
def fits(q: Question, m: InterestMap) -> bool:
    """Whether a question may still race on this map: its goal is there, nothing set aside."""
    goals = {e.name.casefold() for e in m.entries if e.kind == "goal"}
```

```python
def _lift_kinds(m: InterestMap, entry_id: str) -> None:
    """Take an item out of every group; its kinds move up to its groups, where the rules allow."""
    kinds, ups = children(m, entry_id), parents(m, entry_id)
    m.links = [k for k in m.links  # first, so its own place doesn't count against the 2-group limit
               if not (k.kind in ("kind_of", "not_kind_of") and entry_id in (k.a, k.b))]
    day = date.today().isoformat()
    for kind in kinds:
        for up in ups:
            if not _group_error(m, kind, up):
                _link(m, kind, up, "kind_of", day)
```

- **`_levels`**, with a guard against stored loops:

  ```python
  def _levels(m: InterestMap, entry_id: str, step: Callable[[InterestMap, str], list[str]],
              seen: frozenset[str] = frozenset()) -> int:
      """The longest chain from this item, following ``parents`` or ``children``."""
      if entry_id in seen:
          return 0  # a stored loop never recurses forever
      return 1 + max((_levels(m, i, step, seen | {entry_id}) for i in step(m, entry_id)),
                     default=0)
  ```

- **`_from_dict`:** keep only links whose ends are both entries: `ids = {e.id for e in entries}` and `links = [k for k in links if k.a in ids and k.b in ids]  # heals a map an older bug broke`.
