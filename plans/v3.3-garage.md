# v3.3 Real cars in the garage: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The garage sells real cars from a private file on the home server. Each card shows a cut-out picture, the car's stats, and a price at $2,500 a ⭐. A right answer's gas pushes a faster car further.

**Architecture:**
- **`garage.py`** gains a `Garage` (cartoon cars from code, plus real cars read once from `<data>/garage.json`), price and boost rules, and the track drawing for a real car (an SVG `<image>`).
- **`race.py`** multiplies the right-answer step by the car's boost.
- **`app.py`** serves a picture only to someone signed in, and only for an id in the garage.
- **`games.py`** builds the garage cards from the `Garage`.
- **`scripts/lift_car.swift`** cuts a car out of a picture with Apple's Vision.

**Tech Stack:** Python 3.11+, Gradio 6.30, FastAPI, Swift with Vision (macOS 14+), pytest.

**Spec:** [plans/specs/09-play-and-points.md](specs/09-play-and-points.md) (the garage, the gas boost, and the Numbers table, v3.3).

## Global Constraints

- **Price in ⭐** = dollars ÷ 2,500, rounded to the nearest whole ⭐.
- **Gas boost** = √(4.0 s ÷ the car's 0–60), held between ×1.0 and ×1.4. A car with no 0–60 (cartoon cars) is ×1.0.
- **With boost ×1.0 the outcomes stay as in v3.1:** 4–5 right wins, 3 is 2nd, 2 or fewer is 3rd. **At ×1.4:** 3 right wins, 2 is 2nd, 1 is 3rd.
- **Nothing private in the repo** (rule 8): no real car names, prices, or pictures. They live in `<data>/garage.json` and `<data>/cars/`, on the home server only.
- **Pictures are served only to someone signed in,** only for an id in the garage, never a path from the request.
- **A missing or broken garage file leaves the cartoon garage,** and a bad entry is skipped alone.
- **Only the cartoon starter is sold;** a cartoon car someone already owns stays drivable and listed.
- **Code style:** tests use fakes and stay minimal (rule 4); new files go in the code manifest; comment code briefly.

## Review Focus

1. A request for `/cars/../secret.key`, or any id not in the garage: 404, with nothing read from outside `<data>/cars/` (Task 3 test).
2. A garage file with one bad entry (a missing picture, a bad price): the other cars still load (Task 1 test).
3. Someone who owns a paid cartoon car from v3.1: it still shows in their garage as Drive or Driving (Task 3 test).
4. Switching cars mid-day: the next race uses the new car's boost (Task 3, `start_race` takes the driven car's boost).
5. A signed-out request for a picture: refused (Task 3 test).

```python
PRICE_PER_STAR = 2500  # dollars per ⭐
BASE_0_60, MAX_BOOST = 4.0, 1.4  # a 4-second car gets no boost; none gets more than ×1.4
_ID = re.compile(r"^[a-z0-9-]{1,40}$")
_PICTURE = re.compile(r"^[a-z0-9-]{1,40}\.(webp|png)$")


def boost(c: Car) -> float:
    """How far a right answer's gas pushes this car: √(4.0 s ÷ its 0–60), ×1.0 to ×1.4."""
    if c.zero_to_60 <= 0:
        return 1.0  # cartoon cars
    return min(MAX_BOOST, max(1.0, math.sqrt(BASE_0_60 / c.zero_to_60)))


class Garage:
    """The cartoon cars in code, plus real cars from the home server's private garage file."""

    def __init__(self, root: Path | None = None) -> None:
        self.folder = (root or default_data_dir()) / "cars"
        real = sorted(self._load((root or default_data_dir()) / "garage.json"), key=lambda c: c.price)
        self.cars = (CARS[0], *real, *CARS[1:])  # starter, real cars cheapest first, other cartoons
        self._by_id = {c.id: c for c in self.cars}
        self._real = {c.id for c in real}

    def _load(self, path: Path) -> list[Car]:
        try:
            items = json.loads(path.read_text(encoding="utf-8")).get("cars", [])
        except (OSError, ValueError, AttributeError):
            return []  # no file, or a broken one: the cartoon garage
        cars = []
        for item in items if isinstance(items, list) else []:
            try:
                usd, picture = int(item["usd"]), str(item["picture"])
                c = Car(str(item["id"]), str(item["name"]), round(usd / PRICE_PER_STAR), "#000",
                        "", usd, float(item["zero_to_60"]), str(item.get("engine", "")),
                        int(item.get("power_hp", 0)), str(item.get("drive", "")),
                        str(item.get("note", "")), picture)
            except (KeyError, TypeError, ValueError):
                continue  # a bad entry is skipped alone
            if (_ID.fullmatch(c.id) and _PICTURE.fullmatch(picture) and usd > 0
                    and c.zero_to_60 > 0 and c.id not in _BY_ID and (self.folder / picture).is_file()):
                cars.append(c)
        return cars

    def car(self, car_id: str) -> Car:
        """The car with this id.

        Raises:
            KeyError: No such car.
        """
        return self._by_id[car_id]

    def picture(self, car_id: str) -> Path | None:
        """A real car's picture on disk; None for anything else (never a path from a request)."""
        c = self._by_id.get(car_id)
        return self.folder / c.picture if c is not None and c.id in self._real else None

    def sold(self, owned: list[str]) -> list[Car]:
        """What this player's garage lists: the starter, the real cars, and cartoon cars they own."""
        return [c for c in self.cars if c.id == "starter" or c.id in self._real or c.id in owned]

    def svg(self, car_id: str, x: float, y: float, lane: str) -> str:
        """A car on the track: a real car's picture, or a cartoon drawing."""
        if car_id not in self._real:
            return car_svg(car_id if car_id in _BY_ID else "starter", x, y, lane)
        return (f'<g transform="translate({x:.0f} {y:.0f})"><g class="lerni-racer" data-lane="{lane}" '
                f'data-x="{x:.0f}"><image href="/cars/{car_id}" x="-6" y="0" width="72" height="26" '
                'preserveAspectRatio="xMidYMax meet"/></g></g>')
```

    """One garage card: the picture, the name, the facts, and the price."""

```swift
// Cut one car out of a picture with Apple's Vision (macOS 14+), for the private garage.
//   swift scripts/lift_car.swift <picture> <out.png> [x y width height]  (crop from the top-left)
import AppKit
import CoreImage
import Vision

let args = CommandLine.arguments
guard args.count == 3 || args.count == 7, let src = CIImage(contentsOf: URL(fileURLWithPath: args[1])) else {
  print("usage: swift lift_car.swift <picture> <out.png> [x y width height]"); exit(1)
}
var piece = src
if args.count == 7 {  // CoreImage counts from the bottom; the crop is given from the top
  let n = args[3...6].compactMap { Double($0) }.map { CGFloat($0) }
  let rect = CGRect(x: n[0], y: src.extent.height - n[1] - n[3], width: n[2], height: n[3])
  piece = src.cropped(to: rect).transformed(by: CGAffineTransform(translationX: -rect.minX, y: -rect.minY))
}
let request = VNGenerateForegroundInstanceMaskRequest()
let handler = VNImageRequestHandler(ciImage: piece)
try handler.perform([request])
guard let result = request.results?.first else { print("No car found."); exit(1) }
let lifted = try result.generateMaskedImage(ofInstances: result.allInstances, from: handler,
                                            croppedToInstancesExtent: true)
try CIContext().writePNGRepresentation(of: CIImage(cvPixelBuffer: lifted),
                                       to: URL(fileURLWithPath: args[2]), format: .RGBA8,
                                       colorSpace: CGColorSpace(name: CGColorSpace.sRGB)!)
print("Saved \(args[2])")
```
